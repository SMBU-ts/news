Git 大规模托管为何如此困难

Git 的分布式设计使其大规模托管面临固有挑战：packfile 作为存储和网络传输的基础单元，在服务器端成为可用性与…

阅读原文 →
Cursor 博客文章剖析了大规模托管 Git 仓库为何困难。Git 是内容寻址的分布式版本控制系统，其 packfile 二进制格式便于本地处理却不适合服务器大规模管理，对象在 packfile 中随机分布且多为增量存储，导致随机遍历在分布式文件系统上性能极差。GitHub 早期尝试 NFS、GFS、DRBD 等方案均告失败，最终开发了 Spokes 系统：在 packfile 层面运作、将数据以原生 Git 仓库形式存储于本地 NVMe 磁盘，并通过三阶段提交（3PC）共识算法保证多副本强一致，从而成为行业标准的托管架构。
